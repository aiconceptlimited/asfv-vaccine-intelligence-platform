# ASFV Vaccine Intelligence Platform

Computational platform for African Swine Fever Virus (ASFV) multi-epitope vaccine design, integrating epitope discovery, machine learning ranking, construct architecture enumeration, and population coverage analysis.

Part of the [AI Concepts Computational Research Laboratory](https://lab.aiconceptlimited.com.ng).

## Overview

This platform performs systematic in silico design of multi-epitope vaccine constructs against ASFV. It implements a complete pipeline from genome acquisition through final construct validation.

### Key Scientific Results

- Epitope panel: 8 CTL + 4 HTL + 3 B-cell candidates
- Construct architectures enumerated: 25,920
- Machine learning model: SVM (accuracy 0.783 +/- 0.050, 5-seed stability)
- Final candidate: C05_H06_B241 (165 aa)
- Population coverage: Kenyan SLA allele analysis included

## Pipeline

Genome acquisition (NCBI) -> Protein extraction -> Conservation analysis -> Epitope discovery -> ML ranking + Pareto optimization -> Construct architecture enumeration (25,920 designs) -> Multi-objective ranking -> Final construct validation

## Repository Structure

- Snakefile: Snakemake workflow entry point
- workflow/: Snakemake rules, envs, schemas
- config/: Pipeline configuration (YAML)
- src/asfv_platform/: Core Python package
- scripts/: Pipeline stage scripts
- audit/ and audit_complete/: Audit scripts and reports
- data/: Curated scientific data (metadata, reference, processed)
- results/: Validation reports for final construct
- docs/: Pipeline documentation
- tests/: Test suite

## Data Exclusions

This repository does not include:

- Raw genome downloads (data/raw/)
- NetMHCpan raw output (netmhcpan_SLA-*.tsv); parsed versions are included
- Large intermediate files (construct_junctions_all.tsv, construct_orders_all.*)
- The MixMHC2pred third-party tool (available at https://github.com/GfellerLab/MixMHC2pred)

These can be regenerated by running the pipeline from the Snakefile.
