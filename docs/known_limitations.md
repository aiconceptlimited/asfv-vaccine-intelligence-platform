# Known Limitations

## Data Limitations
1. Limited SLA frequency data for East African pigs
2. Some genomes have ambiguous nucleotides
3. CD2v gene missing/truncated in several genomes

## Tool Limitations
1. NetMHCpan-4.1 not trained on all SLA alleles
2. PigMatrix has limited allele coverage
3. No pig-specific proteasomal cleavage predictors

## Computational Limitations
1. No GPU resources on VPS
2. MD simulations limited to 50-100 ns
3. Construct modelling limited to 600 aa (Foldify limit)
