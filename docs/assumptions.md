# Assumptions

## Biological Assumptions
1. All 11 accessions represent complete ASFV genomes
2. GenBank annotations are correct for target genes
3. SLA alleles listed are representative of East African pig populations
4. Protein lengths from literature are accurate references

## Computational Assumptions
1. VPS resources (4 vCPU, 8GB RAM) are sufficient for analysis
2. NCBI Entrez API will remain accessible
3. External web platforms (Foldify, WeNMR) will remain free

## Limitations
- Computational predictions are hypotheses, not experimental validation
- SLA frequency data is based on limited Kenyan study (n=9)
- CD2v status requires verification for some genomes
